ഒരു ഡാഷിൽ മലയാളം അക്ഷരം വരച്ച് അയയ്ക്കൂ.

ചോദ്യം തയ്യാറാക്കുന്ന ടീം — സിനിമയുടെ സൂചന വരയ്ക്കുക

വലിയ പാഡിൽ ഡാഷുകളും ചിഹ്നങ്ങളും വരയ്ക്കൂ. മലയാളം കീബോർഡ് വേണ്ട: സിനിമയുടെ പേര് ഇംഗ്ലീഷ് അക്ഷരങ്ങളിൽ (ഉദാ. Manichitrathazhu) നൽകൂ. ഈ പേര് മറു ടീമിന് കാണിക്കില്ല. ശരിയായ അക്ഷരം ഉറപ്പായാൽ ടീം A മലയാളം അക്ഷരം പട്ടികയിൽ നിന്ന് തിരഞ്ഞെടുക്കും.

ഉത്തരം മറു ടീമിന് കാണിക്കില്ല. വരച്ച അക്ഷരം ശരിയെങ്കിൽ പച്ച ✓, തെറ്റെങ്കിൽ ചുവപ്പ് ✕ അമർത്തുക.

കളിക്കുന്ന വിധം

  1. ചോദ്യം തയ്യാറാക്കുന്ന ടീം സിനിമയുടെ പേര് നൽകുന്നു; അത് മറച്ചുവെക്കും.
  2. മറ്റേ ടീം ഓരോ ഒഴിഞ്ഞ സ്ഥാനത്തും അക്ഷരം വരച്ച് അയക്കും.
  3. ചോദ്യം തയ്യാറാക്കിയ ടീം പച്ച ✓ അമർത്തി ശരിയാണെന്നും ചുവപ്പ് ✕ അമർത്തി തെറ്റാണെന്നും അറിയിക്കും. ചാറ്റും ഉപയോഗിക്കാം.
  4. അഞ്ച് തെറ്റായ ശ്രമങ്ങൾ കഴിഞ്ഞാൽ റൗണ്ട് അവസാനിക്കും.
  5. ഓൺലൈൻ കളിക്ക് Firebase ക്രമീകരിച്ച് GitHub Pages-ൽ പ്രസിദ്ധീകരിക്കണം.
