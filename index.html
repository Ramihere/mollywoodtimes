കളിക്കുന്ന വിധം

  1. ഒരു കളിക്കാരൻ സിനിമയുടെ പേര് മലയാളത്തിൽ നൽകുന്നു.
  2. മറ്റേ ടീം അക്ഷരങ്ങൾ തിരഞ്ഞെടുക്കുകയോ ട്രേയിൽ നിന്ന് ബോർഡിലേക്ക് വലിച്ചിടുകയോ ചെയ്യുന്നു.
  3. ശരിയായ അക്ഷരം സിനിമയുടെ പേരിൽ തുറക്കും.
  4. അഞ്ച് തെറ്റായ ശ്രമങ്ങൾ കഴിഞ്ഞാൽ റൗണ്ട് അവസാനിക്കും.
  5. ഓൺലൈൻ കളിക്ക് Firebase ക്രമീകരിച്ച് GitHub Pages-ൽ പ്രസിദ്ധീകരിക്കണം.
